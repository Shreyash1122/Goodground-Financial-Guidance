# Goodground

A responsive financial guidance website for middle-class families in India. It includes a browser-only monthly budget snapshot, an illustrative savings growth calculator, practical family goal guides, and educational FAQs.

## Run locally

Open `index.html` in a modern browser. No build step or account is required.

## Notes

- Budget entries are calculated in the browser and are not sent to a server.
- The projection is an illustration using an assumed 8% annual growth rate. Returns are not guaranteed.
- Goodground provides general educational information, not personalized financial, investment, tax, legal, or insurance advice.
